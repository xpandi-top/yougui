## 浏览器端到端（已在开发时手测）

首次设置 → 建子位置 → 建容器 → 连续添加 → 追踪数量 + 商品码 → 部分移动 → 撤销 → 搜索路径 → 整盒移动 → 取出 → 生成标签/打印预览/绑定/手输编号跳转 → 连续扫码入库（商品码累加、未知码新建）→ 盘点 → 附件 PDF/照片封面/外链/多关联 → 本地 wrangler 云同步：设备 A 上传、设备 B 加入、云端文件按需下载、并发修改冲突复核、用本机覆盖 → Service Worker 预缓存。

## 真实商品码样例

| 商品 | 条码 | 结果 |
|---|---|---|
| Citadels（Z-Man Games，ZMGZC01） | UPC-A `841333113513` | 按规范绘制的条码图在清晰/缩小/模糊/噪点/倾斜 5°/仿手机 6 种条件下，ZXing 均读出 `841333113513 (UPC_A)`；Chromium 原生 BarcodeDetector 不支持 upc_a，按 EAN-13 读出 `0841333113513`。两者规范化为同一 key，搜索与扫码都命中同一物品。手输 `84133311351`（漏末位校验位）时提示补全为 `841333113513`。 |

商品名查询（0.3.0）实测：本地 Worker 真实请求 UPCitemdb，添加页自动填入「Citadels (Revised Edition)」、分类「Board Games」，结果写入 D1 `product_cache`；Nutella `3017620422003` 由浏览器直连 Open Food Facts 查到。关闭设置后打开添加页无任何查询请求。自动化：`src/__tests__/lookup.test.ts`（解析、查询顺序、缓存、关闭开关）、`worker/test/lookup.test.ts`（代理、缓存 TTL、429 不缓存、upcdatabase 备选、鉴权）。

## 手动清单（发布前，iPhone 实机）

- [ ] Safari 打开 HTTPS 地址；添加到主屏幕后独立启动；安全区与底部导航不被遮挡（375/390/430 宽）。
- [ ] 动态字号放大后无横向滚动；键盘弹出时保存按钮可达。
- [ ] 扫码：首次授权、拒绝后的提示与手输、锁屏/切后台后恢复、暗光、反光；QR、EAN-13、UPC-A 实物各 10 次。
- [ ] 同一码停在镜头内只计一次；移开再对准计第二次。
- [ ] 打印 40×30 mm 样张（实际大小），20 张连续扫码；30×20 mm 评估。
- [ ] 拍照作封面（竖拍方向正确）、选 HEIC、选 PDF、下载原件。
- [ ] 断网（飞行模式）冷启动、增删改、扫码手输；恢复网络后自动同步。
- [ ] 导出 ZIP → 在另一台设备导入。
