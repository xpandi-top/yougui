JavaScript 语法检查与本地脚本行为检查通过：24 路由生成、多对象关联、单处解除关联、独立附件保留、非法 URL 拒绝、PDF 原字节保留、删除与文件释放。原版本曾验证搜索完整路径、取出与撤销。新版未进行真实浏览器视觉或 iPhone 验证；不承诺真实相机、安装和打印兼容。

## 交付边界
这是 PRD 与页面设计，不是生产系统。没有登录鉴权、云端 API、R2/D1、上传失败清理、真实扫码或可扫码标签；没有 Drive/OneDrive 连接、完整 ZIP 数据备份和恢复。ZIP 交付包只是设计文件集合。原型导出的 JSON 仅含本地索引，不含文件本体。

打开 prototype/index.html 查看。页面选择的文件关闭/刷新后不保留；不要用此原型保存唯一一份重要凭证。
