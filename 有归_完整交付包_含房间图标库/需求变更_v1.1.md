# v1.1 · 附件、云存储与无纸化

本次更新已合并到完整 PRD，原收纳、扫码、标签和库存需求保持。

| 阶段 | 本次新增范围 |
|---|---|
| P0 | 私有 R2 文件、D1 元数据、统一附件、多对象关联、独立附件基础入口、照片/PDF、外链、类型备注、照片优化、预览下载删除、权限和上传可靠性 |
| P1 | 自动缩略图、Google Drive Picker、完整数字档案与附件搜索、全量导出/备份/恢复演练 |
| P2 | OneDrive、OCR/购买信息提取、保修提醒、跨云盘迁移、外链失效检测 |

设计决策：独立附件数据能力 P0 即可用，并有“未关联附件”基础列表；完整数字档案页面与搜索仍为 P1。避免附件在未绑定物品时没有访问入口。

照片普通 Photo 保存优化图；收据、发票、保修和其他文档保留原件，即使它们是图片格式。缩略图 P1 不影响 P0 展示优化后的封面图。

解除关联只删除一条关系；删除附件则明确显示影响所有关联。删除外部引用不删除外部云盘/网站原文件。

D1/R2 不存在跨服务单一事务，采用上传会话、幂等完成、状态核查、失败补偿和临时对象清理。签名访问 URL 不作为长期文件引用。

本轮提供页面与规则设计及本地交互演示，没有部署真实云端。引用的 SMALL-APP-ARCHITECTURE 原文未提供，因此不声称已检查其具体规范。
