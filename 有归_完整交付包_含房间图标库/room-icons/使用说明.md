# 有归 · 独立房间图标库 v1.0

本库含 24 枚房间和功能区域图标，独立于现有页面和物品图标库。已生成资源与浏览页面，本轮未修改原型的房间数据或接入房间选择器。

## 空间范围
客厅、餐厅、厨房、卧室、儿童房、客房、书房、工作室、浴室、卫生间、洗衣房、衣帽间、玄关、走廊、阳台、露台、花园、车库、储藏室、食品储藏室、地下室、阁楼、健身房、工具房。

同类空间复用图标，以名称区分，例如主卧/次卧使用卧室，客卫/主卫使用卫生间。房间图标不限制位置自由层级，也不会自动决定房间分类。

## 文件
- index.html：可直接打开的独立图标库，支持中文搜索、空间分类、20/24/32/48 px 预览及墨绿/朱砂切换。
- svg/：24 枚独立 SVG（24×24，currentColor，可缩放改色）。
- png/：24 枚 96×96 透明 PNG（墨绿 #35463D）。
- sprite.svg：合并 symbol 库，ID 采用 rooms-* 命名空间，与 ui-* / items-* 分开。
- manifest.json：名称、类别、稳定 ID 和图形路径清单。
- rooms.js：ES Module 导出的 ROOM_ICONS 字典，用于后续组件接入。
- 房间图标总览.svg / .png：全部图标的视觉总览。

## 设计规范
与现有新中式设计统一：24×24 基准，1.6 px 线宽，圆端点、圆连接，无渐变，无字体依赖。房间图标优先描述空间场景，而非仅用单件物品代替空间。墨绿 #35463D 为常态，朱砂 #934A3A 可用于选中状态，宣纸底色 #F4EFE5。

推荐页面显示 24–32 px；按钮点击区至少 44×44 px。图标配房间名称；纯图标按钮需提供无障碍名称，选中态不能只依赖颜色。

## 建议接入
位置实体增加可选 room_icon_key，保存如 rooms-kitchen 的稳定 ID；不把 SVG 路径复制到每个房间。无可识别 ID 时回退通用 ui-room。图标作为前端静态资源，不上传 R2、不占用户附件额度。

用单文件 SVG 直接作为 img 时，颜色为文件自身颜色，父级 CSS color 不会传入；需动态改色时使用内嵌 SVG 或 sprite。原 SVG 带 title，重复内嵌需使用独立标题 ID 或改为装饰图标。

Sprite 用法：
```html
<svg width="24" height="24" viewBox="0 0 24 24" fill="none"
     stroke="currentColor" stroke-width="1.6"
     stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
  <use href="./sprite.svg#rooms-kitchen"></use>
</svg>
```
本地 file 模式可能限制外部 sprite；独立浏览页内嵌路径，不依赖 sprite 加载。
