# 有归 · iPhone PWA 页面设计

## 使用
打开 prototype/index.html。无需联网或安装依赖，推荐桌面浏览器查看完整设计说明；手机浏览器显示单栏全屏。样例修改保存在当前浏览器，更多页可重置。Safari 本地文件能否执行受打开方式影响；遇到限制请在电脑浏览器打开或通过 HTTP 静态服务器预览。

## 页面架构
首页 → 全局搜索 / 物品详情 / 房间详情 / 扫码
位置 → 房间 → 子位置/容器 → 物品 → 移动/取出/容器开关
扫码 → 普通/连续 → 操作模式 → 位置 → 识别 → 待提交 → 确认
物品 → 极简连续创建 / 详情 / 盘点 → 差异复核
更多 → 标签中心 → 空码预览 → 系统打印；使用与兼容说明
空白 QR → 绑定已有物品 / 创建物品

## 高保真设计规范
- 基准宽 390–430 px，375 px 下无横向滚动。桌面居中展示移动界面并附设计导航。
- 背景 #F7F6F0；主色 #234D40；辅助绿 #E9EEE7；提醒色 #F9E9D8；正文 #243E35。
- 系统中文字体；主标题 30 px，分组标题 19 px，正文 16 px，路径 12 px。
- 24 px 页面留白；卡片圆角 20 px；主卡圆角 24 px；底部导航为拇指操作区，扫码突出。
- 不依赖物品摄影，用符号缩略图降低创建成本。正式产品照片缺省时保持相同卡片结构。
- 重点视觉：完整位置路径、当前扫码模式与位置、数量是否追踪、未提交/已保存状态。

## 建议体验路径
1. 首页 → 搜索 HDMI → 详情 → 移动 → 车库 → 搜索确认新路径 → 撤销。
2. 位置 → 书房 → 储物柜 → 配件盒 A → 添加 → 连续输入两件物品。
3. 扫码 → 连续 → 入库 → 厨房 → 模拟商品 EAN → 清单 → 确认 → 查看电池数量。
4. 更多 → 盘点 → 输入实际数 → 查看差异 → 确认调整。
5. 更多 → 标签 → 数量 → 预览 → 系统打印；扫码 → 空白 QR → 绑定入口。
6. 尝试库存不足、空搜索、非整数盘点、非空容器关闭，验证错误提示。

## 设计覆盖与限制
HTML 提供 16 个主要页面/状态：home、items、places、location、detail、add、move、scan、manual、review、count、diff、bind、labels、print、more，另有 guide。

实际可用：名称/路径搜索、位置浏览、极简连续创建、数量取出、整条移动、容器开关、全家数量盘点及差异复核、模拟连续扫码与清单、标签版式打印、撤销。

仅流程演示：扫码取景不连接相机；标签为明确标记的不可扫码图案；绑定不持久化标签关系；连续盘点仅演示“已见”；移动演示整条库存而非部分数量。未实现登录、服务端事务、唯一标签、商品库、文件标签导出、照片、同步、真实 PWA 安装和家庭共享。

后续应补齐的生产页面：首次家庭创建、创建子位置、完整物品编辑、商品多来源选择、部分移动数量选择、盘点范围/快照冲突、标签重绑/停用、日志与纠错、离线草稿和版本冲突。需求与验收以 PRD 为准，原型不替代完整实现。

## iPhone 验证清单
Safari 与主屏幕各验证：375/390/430 px，安全区，动态字号，键盘弹出，后置摄像头权限、拒绝恢复、锁屏恢复、旋转、暗光、UPC/EAN/QR 实物解码，离线草稿，重复提交。打印需指定真实设备与纸张，不能由本原型判定兼容。


## 新中式视觉修订 · 2026-10-13
现有原型已改为新中式主题，交互与需求优先级保持原版本。
- 宣纸色 #F4EFE5 为底，墨绿 #35463D 承载主视觉，朱砂 #934A3A 用于主操作和印章。
- 中文标题使用系统宋体衬线栈，正文保留系统无衬线字体，兼顾东方气质与小屏可读性。
- 采用细框、低圆角、轻纸纹、圆窗线条与“归”字印章；避免装饰压过位置路径和库存信息。
- 房间和物品缩略图改为汉字标识，减少彩色表情符号，形成统一的视觉语言。
- 字体依赖设备系统字体；具体字形会随 iPhone / macOS / Windows 略有差异。


## v1.1 附件与数字档案页面
保留新中式视觉与原五项主导航。物品详情新增“随物档案”；更多增加“未关联附件 P0”“家庭数字档案 P1 预览”“存储与备份”。

新增 7 个页面：archive（未关联基础列表 / P1 全档案）、attachmentAdd、attachmentDetail、attachmentPreview、attachmentLinks、attachmentEdit、storage。合计 24 个主要页面/状态路由；同一路由下的模式切换不另计。

体验路径：
1. 物品 → AA 电池 → 随物档案 → Costco 购物收据 → 查看两个关联 → 解除其中一个 → 另一关联仍保留。
2. 更多 → 未关联附件 → 房屋维修记录 → 管理关联 → 选择物品及房间 → 保存。
3. 附件添加 → 选择本地 PDF → 文档/收据类型 → 保存 → 预览/下载；原文件不压缩。
4. 附件添加 → 拍照/选择照片 → 照片类型 → 保存优化图 → 关联物品 → 设为封面 → 搜索结果显示本次会话封面。
5. 更多 → 家庭数字档案（P1）→ 按名称和类型筛选。
6. 更多 → 存储与备份 → 下载本地索引 JSON，查看计划中的云存储与完整 ZIP 边界。

实际本地交互：新增文件选择与当前会话预览、PDF/图片下载、Photo 长边 1600 px 优化、外部 URL 校验和引用、名称/类型/备注编辑、多对象关联/解除关联、独立附件列表、确认后删除、封面设定、附件名称/类型筛选和元数据索引导出。

限制：当前没有 R2/D1、登录、家庭权限、服务器 MIME 验证、上传会话、云端失败恢复、缩略图服务、Drive Picker、完整 ZIP 备份或恢复。文件只保留于页面会话；刷新后元数据仍在，文件须重选；示例收据为示意内容，非真实文件。Photo 压缩取决于浏览器解码，HEIC 不支持时提示换格式或按文档保留原件。

本轮脚本检查覆盖 24 个路由生成、单处解除关联、多关联保留、独立附件、非法 URL 拒绝、PDF 字节保留、删除与本地文件释放。未进行新版 iPhone 或真实云端测试；原版首页截图不能代表当前主题。


## v1.2 图标设计与接入
新增 32 枚页面图标、48 枚物品图标；资源与规范位于 icons/。五项主导航、房间卡片、库存操作、附件类型及更多入口开始使用统一 SVG 图标。

创建页加入可选图标面板，搜索/类别筛选不清空其他表单字段；详情加入更换图标与取消封面入口。新增 iconPicker 路由，现为 25 个主要页面/状态。物品显示优先级为有效照片 → 自选图标 → 默认收纳盒，替代旧版汉字占位图。图标只是识别辅助，不决定分类或容器能力。

可先打开 icons/index.html 浏览全部图标，或查看 icons/图标总览.png。独立图标包包含 SVG、PNG、合并 sprite 与清单，供后续 React/MUI 实现使用。代码与图标总览已检查；本轮未取得真实 iPhone 页面截图。
