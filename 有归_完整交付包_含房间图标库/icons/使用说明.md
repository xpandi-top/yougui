# 有归 · 新中式图标系统 v1.0

共 80 枚：32 枚页面操作图标，48 枚物品图标。所有形状均为本次绘制的代码矢量图形，不依赖外部字体或在线图标库。

## 文件
- index.html：独立可浏览图标库，支持名称搜索、类别筛选、墨绿/朱砂切换、逐枚 SVG 下载。
- ui/*.svg：页面图标，24×24、currentColor。
- items/*.svg：物品图标，24×24、currentColor。
- png/ui 与 png/items：96×96 透明 PNG，墨绿色，用于不支持 SVG 的工具。
- sprite.svg：合并的 SVG symbol 库，ID 与 manifest.json 一致。
- icons.js：原型用内嵌图形与渲染函数，不依赖网络。
- manifest.json：稳定 ID、名称、类别和路径数据。
- 图标总览.svg / .png：全部图标的设计总览。

## 设计规则
24×24 基准网格，主要形状落在 2–22 区间，1.6 px 描边，圆端点、圆连接，单色、无渐变、无字体转图形。默认墨绿 #35463D；选中/重要操作使用朱砂 #934A3A；衬底为宣纸 #F4EFE5。大尺寸详情图标可以作光学校正，避免线条过重。不要给图标增加窗棂或印章细节以牺牲小尺寸辨识度；东方气质由整个界面配色、留白和线条共同呈现。

UI 图标默认显示 20–24 px，物品列表 28 px，选择器 27 px，详情 72 px。可点区域至少 44×44 px。选中态同时用边框与 aria-pressed，不能只变颜色。图标配合文字使用；纯图标按钮必须有可访问名称。装饰 SVG 使用 aria-hidden=true、focusable=false。

## 物品规则
显示顺序：有效封面照片 → 用户选择的 icon_key → 默认收纳盒。不要求创建时必选图标。照片丢失时不把文件当作已经删除，应显示附件失效说明并回退所选图标。

当前 48 枚按收纳、数码、工具、衣物、厨卫、文具、出行、家居、健康、生活分组。分组仅帮助挑选，不会自动写物品分类；收纳盒图标也不会启用容器功能。

原型入口：添加物品 → 物品图标；物品详情 → 物品图标 → 更换。详情中“取消封面，使用图标”只取消封面引用，照片附件仍保留。

原型兼容旧数据：四条默认样例按名称给出线材/电池/背包/电钻图标，其他缺失或未知 ID 回退收纳盒；正式版本迁移时统一补默认 icon_key，避免靠名称推断。

## 开发接入
建议在 Entity 和 Stock 增加可选 icon_key 字段，以 manifest 中的 items-* 稳定 ID 保存；不要保存完整 SVG 字符串到每条物品。图标资源随前端版本打包，属于公共静态资产，不占用户附件配额，不上传 R2。升级不得复用既有 ID 表示不同物品。

内嵌 SVG 可直接使用 currentColor；外部 img 引入 SVG 时，父元素颜色不会自动传入，需使用内嵌组件或改写 SVG。单文件 SVG 带 title；批量同页内嵌时应生成独立标题 ID 或按装饰图标处理，避免重复 ID。

Sprite 示例：
```html
<svg width="24" height="24" viewBox="0 0 24 24"
     fill="none" stroke="currentColor" stroke-width="1.6"
     stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
  <use href="./sprite.svg#items-battery"></use>
</svg>
```
本地 file 模式的外部 sprite 引用可能受浏览器限制；单文件原型采用内嵌路径，离线不依赖外部 sprite。
